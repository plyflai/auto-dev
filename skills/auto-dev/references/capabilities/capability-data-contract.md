# Capability: Data And Contract

## Enable When

- 数据模型、Schema、公共 API、协议、配置真相源或外部契约变化。
- 需要迁移历史数据、兼容旧调用或收缩字段/状态。

## Hard Gates

- 建立生产者、消费者、版本与错误语义清单。
- 明确 expand、migrate、contract 的安全顺序。
- 写入前具备备份、幂等、重试、校验与回滚方案。
- 对未知旧数据和部分失败定义处理方式。

## Verification

- 契约测试覆盖新旧消费者需要的窗口。
- 迁移在代表性数据上演练，校验数量与关键不变量。
- 回滚路径实际验证，或明确说明不可回滚及批准来源。

## Completion

- 新旧契约边界与淘汰条件明确。
- 数据完整性、失败恢复和消费者兼容均有证据。
