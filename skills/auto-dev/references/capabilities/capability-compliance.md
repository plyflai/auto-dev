# Capability: Compliance

## Enable When

涉及权限、认证、支付、安全、隐私、合规或敏感数据处理。

## Hard Gates

- 明确资产、信任边界、威胁主体、允许动作和审计要求。
- 使用最小权限、默认拒绝和服务端权威校验。
- 敏感数据不进入日志、临时文件、截图或运行回执。
- 安全相关行为变化必须由用户确认，不能作为交付保障静默加入。

## Verification

- 覆盖允许、拒绝、越权、失效凭据和审计路径。
- 对支付或高价值动作验证幂等、重放与部分失败。
- 需要时安排独立安全审查，但避免与普通质量审查重复。

## Completion

- 权限与数据流可追溯。
- 拒绝路径、审计证据和残余风险明确。
