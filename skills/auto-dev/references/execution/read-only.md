# Read Only

只读请求使用 CodeGraph 与模型能力直接给出证据，不初始化 Direct 或 Team 记录；代码导航契约见 [code-navigation.md](../control-plane/code-navigation.md)。导航结果不可用、stale、为空或异常狭窄时，记录原因并做 1-2 个定向 fallback；证据足以回答核心请求后停止。

## Explain

定位入口、核心调用链、关键分支、数据流和测试面。独立读取可并行，有依赖时保持串行并在回答前综合；优先给文件、符号、命令或运行证据，再解释行为，不主动修改代码。

## Survey

输出模块分布、入口、关键接口面、复用点、测试面和高风险区。宏观索引不能替代后续写入任务的精确调查。

## Review / Diagnose

按严重性列出有证据的问题、影响与缺失测试。诊断只确定原因和证据；用户未要求修复时不写入。

## 完成条件

- 结论可追溯到当前仓库事实。
- 未把只读请求扩展为产品写入。
- 用户后续要求修改时转 Requirement Intake。
