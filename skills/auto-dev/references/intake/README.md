# Intake Router

进入条件：产品写入前需要收敛 workspace、当前 turn 需求、低风险 patch 或主结果契约。

- Product Write 的需求分类、确认与 Requirement Diff：[requirement-intake.md](requirement-intake.md)
- Git/local workspace 建立与迁移：[pre-git-control.md](pre-git-control.md)
- 无 active Task 的受限短 patch：[quick-write.md](quick-write.md)
- Outcome、coverage 与 Proof 结果契约：[outcome-contract.md](outcome-contract.md)

只读请求与已授权执行不预读本目录全部内容；由 `mode-index.md` 和 `SKILL.md` 指向当前 leaf。
